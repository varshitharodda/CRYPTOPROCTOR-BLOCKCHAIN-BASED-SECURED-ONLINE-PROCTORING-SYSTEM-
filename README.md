# CryptoProctor – Blockchain Based Secured Online Proctoring System

## 📌 Project Overview

**CryptoProctor** is a secure online examination proctoring system developed using blockchain-inspired security concepts and web technologies. The project is designed to monitor online examinations, maintain exam integrity, and provide secure authentication and monitoring features for students and administrators.

The system helps educational institutions conduct secure online exams by reducing malpractice, monitoring suspicious activities, and protecting examination data.

# 🧠 Working of the System

1. Admin creates and manages examinations.
2. Students log in securely.
3. Online exams are conducted through the web platform.
4. The system monitors exam activities.
5. Suspicious actions can be detected and tracked.
6. Examination records are securely maintained.
7. Results and reports are generated.

# ⚙️ Installation & Setup

## Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/Cryptoproctor-Blockchain-Based-Secured-Online-Proctoring-System.git
```

## Step 2: Navigate to Project Folder

```bash
cd Cryptoproctor-Blockchain-Based-Secured-Online-Proctoring-System
```

## Step 3: Install Required Dependencies

```bash
pip install django
```

## Step 4: Run the Server

```bash
python manage.py runserver
```

## Step 5: Open in Browser

```bash
http://127.0.0.1:8000/
```
